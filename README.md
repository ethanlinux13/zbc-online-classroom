# ZBC Online Classroom PWA

A lightweight Progressive Web App for Zambales Bible College online classes.

## Features
- Automatically detects Monday–Thursday class day in Asia/Manila timezone
- One-tap Zoom and Discord buttons
- Weekly class schedule
- Announcements
- Installable PWA
- Offline shell via service worker
- Mobile-first responsive design
- Easy editing through `config.js`

## Customize
Open `config.js` and update:
- `zoomUrl`
- `discordUrl`
- Monday–Thursday subject/instructor/time
- announcements

## GitHub Pages
Create a repository named `zbc-online-classroom`, upload these files to the default branch, then enable GitHub Pages from the repository branch root.
